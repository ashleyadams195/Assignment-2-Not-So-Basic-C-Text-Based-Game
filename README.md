## Description
This game uses ANSI codes to display a visual map and color the different items, bc it doesn't make any sense why we'd make a game with just text. thats so boring. You are the red X and it moves around the MAP as you interact with the game.
The goal of the game is to hack into the mansions servers. you break innto the house and try to navigate aroune while not getting caught.

## Keys / List of Valid Commands
### Intro
In the intro you can skip the line by line toggle with the SPACE bar, to go message by message just continue with ENTER
### Game Play
The game uses AWSD keys mainly. A = interact with an object, W = go up, S = go down, and D = pickup an item to put in inventory. The items are used automatically once in inventory.
You may also need to use the number keys as prompted for a code.
